## Core Principle

Enterprises adopt autonomous agents faster when governance, identity, and compliance are inherited from existing platform relationships rather than introduced as new systems to evaluate.

## Evidence

Same week (Mar 30-31, 2026):
- **Microsoft Copilot Cowork GA** — multi-model, multi-step background agent inside M365 compliance framework
- **Salesforce Slackbot** — 30 AI features inside existing Salesforce permissions + MCP client
- **Sycamore $65M seed** (former Atlassian CTO + Coatue/Lightspeed) — stand-alone "trusted agent OS" for when platforms don't own the trust relationship

The anomalously large Sycamore round validates governance as a distinct investment category.

## When to Apply

Deciding where to deploy agents for enterprise clients — start inside existing platforms (CRM, M365, Slack) before proposing new agent systems.

## Boundaries

Platform agents lose when platform context/capability is genuinely inferior and the capability gap exceeds the governance savings.
